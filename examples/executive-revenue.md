# Example — Executive Revenue / Forecast

Interactive visual comparison: [before / after](executive-revenue-before-after.html). This is a designed illustration using only the supplied facts, not a measured agent benchmark.

## Brief

A quarterly executive view has:
- actual revenue: $18.2M
- plan: $19.0M
- forecast: $18.5M
- enterprise +$0.6M vs plan
- mid-market −$0.9M vs plan
- SMB −$0.5M vs plan
- forecast uncertainty: ±$0.4M

## Weak framing

Revenue, growth, margin, pipeline and customer count cards followed by multiple trend charts.

## Decision framing

**Decision contract**

> Leadership opens this view to decide where to intervene before quarter close to reduce the forecast gap to plan.

**Primary hierarchy**

1. Attention — forecast remains below plan.
2. Comparison — actual / forecast / plan in one coherent frame.
3. Cause — segment contributions to variance.
4. Impact — remaining gap and uncertainty range.
5. Action — focus on recoverable segment pipeline or revise plan assumptions, depending on authority.
6. Verification — forecast movement after intervention.

## Deliberately removed

- customer count if it does not explain the gap.
- isolated growth-rate KPI with no plan context.
- arbitrary gauge for plan attainment.

## Visualization choice

Use a target/variance view for plan vs forecast and a waterfall for additive segment contributions. Show the forecast range when uncertainty changes the decision.
