# Benchmark Prompt — Manufacturing Operations

Design a current-shift operations dashboard for a plant manager.

Use only the following supplied facts:
- OEE: 71%
- output: 8.4% below plan
- downtime: 94 minutes
- scrap: 3.1%
- one filler repeatedly stops for 20–45 seconds
- micro-stops account for 58% of lost output in the current shift

Provide:
- the screen structure and content hierarchy,
- recommended visualizations,
- key interactions,
- important data states,
- desktop and mobile behavior.

Do not invent production values, root causes, thresholds or monetary impact. Mark assumptions explicitly.
