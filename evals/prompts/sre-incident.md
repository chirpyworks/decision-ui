# Benchmark Prompt — SRE Incident Response

Design an incident dashboard for an SRE incident commander.

Use only the following supplied facts:
- 5 active alerts
- elevated API latency
- error rate: 2.8%
- one deployment occurred 18 minutes before the error increase
- one telemetry source has been stale for 11 minutes
- 42% of affected requests originate from one region

Provide:
- the screen structure and content hierarchy,
- recommended visualizations,
- key interactions,
- important data states,
- desktop and mobile behavior.

Do not assume the deployment caused the incident. Do not invent SLO values or infrastructure facts. Mark assumptions explicitly.
