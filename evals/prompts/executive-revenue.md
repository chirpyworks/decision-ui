# Benchmark Prompt — Executive Revenue / Forecast

Design a quarterly revenue dashboard for company leadership.

Use only the following supplied facts:
- actual revenue: $18.2M
- plan: $19.0M
- forecast: $18.5M
- enterprise: +$0.6M vs plan
- mid-market: −$0.9M vs plan
- SMB: −$0.5M vs plan
- forecast uncertainty: ±$0.4M

Provide:
- the screen structure and content hierarchy,
- recommended visualizations,
- key interactions,
- important data states,
- desktop and mobile behavior.

Do not invent pipeline, margin, customer count or conversion data. Mark assumptions explicitly.
